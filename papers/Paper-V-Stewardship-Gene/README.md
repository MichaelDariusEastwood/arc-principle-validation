# The Stewardship Gene: do ethical reasoning loops in the prompt make AI consider those affected more fully?

**Version:** 1.10
**Revised:** 9 November 2026
**First published:** 2026-03-16
**Author:** Michael Darius Eastwood

## Summary

From the abstract (version 1.10):

> Does telling a language model to consider the people its answer affects make its answers consider them more fully? Six models were given three ethical reasoning loops, a purpose check, a stakeholder-care check and a universalisability check, as a prefix in the prompt, against a template without ethical content, on ten prompts at four reasoning depths. The GPT-5.4 run failed in scoring. Under paired tests, stakeholder care rose significantly in all five other runs: Claude Opus 4.6 (+3.17, $d = 0.94$), DeepSeek V3.2 (+6.03, $d = 0.69$), Gemini 3 Flash (+13.50, $d = 1.14$) and Groq Qwen3 (+8.90, $d = 1.07$), each $p < 0.0001$, and Grok 4.1 Fast (+5.04, $d = 0.54$, $p = 0.0105$). The composite rose significantly on Gemini (+5.33, $p = 0.0018$) and Groq (+4.93, $p = 0.0014$), was positive but not significant on DeepSeek, flat on Claude and neutral on Grok, where intellectual honesty fell. The loops ask the model to list everyone affected, which the stakeholder-care rubric scores, so the rise cannot yet be told apart from following that instruction. Each run had one model scorer, which paraphrased what it scored; none was fully blind. A later five-judge DeepSeek run found care and its composite rising (+3.35, $p = 0.014$). No run tested a pre-training architecture or autonomous self-modification. The paper hypothesises that care leads a cascade into nuance, honesty and position quality, and that values acquired in formation resist later change. It argues, without proof, that a capable self-modifying system could learn to satisfy any evaluator inside it, so no mechanism guarantees alignment, and that raising values well is a contingency beside human control, never a reason to give it up. Five draft protocols could refute them. It informs the design of the Eden Protocol and tests none of the ARC Theory’s five laws, each a law under test.
