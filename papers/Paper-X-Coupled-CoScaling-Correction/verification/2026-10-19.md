## Limits of this execution

A direct git clone could not resolve github.com in the container; the connected
GitHub API was used to read the pinned repository and write the correction.
An attempted separate system-site-packages virtual environment did not expose
SciPy/pytest and could not install missing packages offline. The successful run
therefore used the preinstalled execution environment, not a newly downloaded
clean environment. CI is configured to install dependencies on Python 3.11 and
3.13; its results are a separate remote record, not established by this log.

Only the requested independent theorem suite, its deliberate mutants, and the
stated static checks were run locally. This is not a claim that the full repository
suite, other papers, original harness, original 14-test baseline, or real-model
experiments were executed. Finite regression tests do not establish infinite-time
proofs, universal applicability, or empirical AI safety.

The replacement proofs are in `THEOREMS.md`. The historical HTML/PDF mirrors,
OSF deposits, website, registered predictions and archived pilot outcomes are
unchanged. A published manuscript release incorporating these replacements is
not part of this local execution record.
