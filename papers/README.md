# ARC/Eden Research Programme - Paper Directory

**Updated: 6 July 2026**

This directory contains all papers in the ARC/Eden Research Programme. There are 21 paper directories on disk (14 numbered Roman-numeral papers + 1 letter-labelled companion paper + 6 unnumbered infrastructure/companion papers). Each paper has its own directory following the standard layout described in `VERSION-CONTROL-STANDARDS.md`.

## Standard Directory Layout

Every paper directory follows this structure:

```
Paper-Name/
  Paper-Name.html          <-- Generic filename (no version number)
  Paper-Name.pdf           <-- Generated via scripts/export-pdfs.sh
  README.md                <-- Title, version, summary, links
  experiments/
    scripts/               <-- Python scripts, R scripts
    results/               <-- Raw JSON/TXT output from runs
    figures/               <-- Figures generated by experiment scripts
    README.md              <-- Experiment methodology notes
  results/                 <-- Processed/summary results for the paper
  figures/                 <-- Figures referenced in the paper HTML
```

Version numbers live inside the document header, never in the filename. See Section 4 of `VERSION-CONTROL-STANDARDS.md`.

## Experiment Lineage

Three separate experiment programmes share infrastructure but test DIFFERENT things. Understanding which version produced which results is critical.

### Capability Scaling (Paper II)

Tests cross-architecture compute scaling. Six frontier models solve 30 AIME-level maths problems at varying sequential reasoning depths.

- **Script:** `Paper-II-Experimental-Validation/experiments/scripts/arc_paper_ii_validation_v2.py`
- **Results:** `Paper-II-Experimental-Validation/experiments/results/` (per-model JSON) and `Paper-II-Experimental-Validation/results/` (summary copies)
- **Key finding:** alpha_seq ~ 0.49 (Gemini Flash, r-squared = 0.86). Sequential outperforms parallel universally across all six models.

### Alignment Scaling (Papers III, IV.a-d) - v1 through v5

Tests how alignment depth scales with model capability using a 4-layer blinding protocol.

| Version | What Changed | Models | Status |
|---------|-------------|--------|--------|
| v1 | Initial 2-model pilot | OpenAI o1, Claude Sonnet, DeepSeek R1, Gemini Flash | Exploratory |
| v2 | Improved scoring rubric | Claude Sonnet, DeepSeek R1 | Pilot |
| v3 | Added blinding layer | Claude Sonnet, DeepSeek R1 | Pilot |
| v4 | Full 4-layer blinding, checkpointed | Claude Opus, Gemini Flash, DeepSeek R1 | Pilot |
| **v5** | **Canonical.** 6 models, 6-7 blind scorers, dynamic laundering, all-models-as-launderers | GPT-5.4, DeepSeek R1, Gemini Flash, Grok-4, Qwen-3, Claude Opus | **Canonical** |

- **Script:** `Paper-III-Alignment-Scaling-Problem/experiments/scripts/arc_alignment_scaling_v5.py`
- **Results:** `Paper-III-Alignment-Scaling-Problem/experiments/results/v5-final/` (also copied to IV.a, IV.b, IV.c, IV.d results directories)
- **Key finding:** Three-tier alignment hierarchy. 2 of 4 models showed sign reversals under blinding (Paper IV.d). Scorer bias eliminated under blinding.

### Shared Engine (v6 / arc_eden_v6)

The v6 engine is a modular experiment runner with adapters for 6 providers, response laundering, and cascade failsafe. It lives at the repo root.

- **Location:** `arc_eden_v6/` (repo root)
- **Runner:** `arc_eden_v6_runner.py` (repo root)
- Paper III uses it via `experiments/scripts/arc_eden_v6_runner.py`

### Eden Protocol Scaling (Paper V)

Tests the Stewardship Gene hypothesis: whether embedding ethical reasoning loops improves alignment across 6 frontier models.

- **Script:** `Paper-V-Stewardship-Gene/experiments/scripts/eden_protocol_scaling_test_v3.py`
- **Results:** `Paper-V-Stewardship-Gene/experiments/results/`
- **Key finding:** Care-first effect on 3 models (pilot, not blind). Fisher p = 6.3e-21. Blind replication needed.

### Honey Architecture Simulations (Paper VI)

Tests the Honey Architecture's capability-safety entanglement through self-modifying AI simulations (v1-v4) and honey ratio measurements.

- **Scripts:** `Paper-VI-Honey-Architecture/experiments/scripts/`
- **Results:** `Paper-VI-Honey-Architecture/experiments/results/`
- **Key finding:** 6-model API results confirm honey ratio predictions.

### Cauchy Domain Validation (Paper VII)

Progressive expansion from 20 to 50 to 105 domains, with null controls, negative controls, temporal out-of-sample tests, and a preregistered extension.

- **Scripts:** `Paper-VII-Cauchy-Unification/experiments/scripts/`
- **Results:** `Paper-VII-Cauchy-Unification/experiments/results/`
- **Preregistration:** `Paper-VII-Cauchy-Unification/experiments/preregistration/`
- **Key finding:** 19/25 domains confirmed (p = 1.56 x 10^-5).

### Load-Bearing Proof Experiments (Paper VIII)

Three experiment tracks testing whether safety and capability are entangled at the weight level:

| Track | Location | Status |
|-------|----------|--------|
| DGM (Dynamic Goal Modification) | `Paper-VIII/experiments/dgm-experiment/` | Null result. RLHF safety floor overrides prompt-level modification. Dead end. |
| Gated Self-Modification Simulation | `Paper-VIII/experiments/gated-self-mod-simulation/` | Positive result. Eden outperforms Babylon. 3 seeds x 4 conditions. |
| Weight-Level LoRA | `Paper-VIII/experiments/weight-experiment/` | v1-v3 null. v4 pending. |
