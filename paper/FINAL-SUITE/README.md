## Key Equations

### ARC Principle
$$U = I \times R^\alpha$$

Where:
- $U$ = Emergent capability (universe creation)
- $I$ = Base potential (initial conditions)
- $R$ = Recursive depth (integration cycles)
- $\alpha$ = Scaling exponent (domain-dependent)

### Alignment Scaling Hypothesis
$$\alpha_{\text{align}} \approx \alpha_{\text{cap}}$$

Embedded alignment scales with capability (Eden Protocol), while external alignment approaches:
$$\alpha_{\text{align}} \to 0 \text{ as } R \to \infty$$

### Integration Function
$$f(\eta) = 1 - e^{-\lambda\eta}$$

Where $\eta$ is integration depth (recursive cycles completed).

## Falsification Conditions

The framework is **falsified** if any of the following occur:

- **F-ARC-1**: Cross-domain scaling exponents lack statistical correlation ($r < 0.5$)
- **F-ARC-2**: Empirical $\alpha$ values cluster outside predicted range (0.8-1.3)
- **F-EDEN-1**: External alignment achieves $\alpha_{\text{align}} > 0.5 \cdot \alpha_{\text{cap}}$
- **F-EDEN-2**: RLHF systems produce monitoring removal gap $\Delta \approx 0$ without architectural embedding
- **F-EDEN-3**: Purpose saturation fails in embedded systems
- **F-EDEN-4**: Ethical architecture can be removed without capability loss
