# Start here

**In one screen.**

- **Each document** of this project has its own component and DOI, listed below. Every link ever given out serves the document's newest version, with every earlier version in the file's history.
- **The code, data and recorded outputs** are on GitHub, in the public repository [arc-principle-validation](https://github.com/MichaelDariusEastwood/arc-principle-validation). The table below names each document's code folder.
- **The registered study units** each have a registration and, once run, a results component: Unit 06 ([registration](https://doi.org/10.17605/OSF.IO/RV2B5), [results](https://doi.org/10.17605/OSF.IO/4BPHG)), Unit 83 ([registration](https://doi.org/10.17605/OSF.IO/MN73W), [results](https://doi.org/10.17605/OSF.IO/98HKR)), Unit 82 ([registration](https://doi.org/10.17605/OSF.IO/JUFG4); not yet run) and Unit 83b ([registration](https://doi.org/10.17605/OSF.IO/4HK32); not yet run).
- **This project's own storage.** `archive` is in use: the papers' PDFs at their first addresses. `code`, `data`, `experiments` and `figures` are not in use: what the project stored from January to July 2026, kept as it was stored. `paper` was never filled. Every folder has a `00-READ-ME.md`.
- **Licence.** The papers are CC BY 4.0. The study code and data are all rights reserved, with the [Replication Licence 1.0](https://github.com/MichaelDariusEastwood/arc-principle-validation/blob/main/LICENCE-REPLICATION.md).

## The files in this project's own storage

| Folder | In use? | What it holds |
|---|---|---|
| top of the storage | yes | the papers' own HTML editions, each at the address OSF gave it when first stored and receiving every new version; copies of the Priority & Provenance record of July 2026, whose earliest files are in the Priority Index component, [osf.io/h3r95](https://osf.io/h3r95/); and `EXPERIMENTS-INDEX.md` as it stood on 4 July 2026 (the current one is [on GitHub](https://github.com/MichaelDariusEastwood/arc-principle-validation/blob/main/EXPERIMENTS-INDEX.md)) |
| `archive` | yes | the papers' PDFs at their first addresses. A file's name may be older than its contents: each file receives every new version of its paper. A file named "older copy" is an earlier address of the same paper and receives every new version too. |
| `code` | no | code stored on 17 and 22 January 2026 and one archive of 4 July 2026 |
| `data` | no | data stored on 17 and 22 January 2026 and results archives of 4 July 2026, named by paper |
| `experiments` | no | experiment scripts and results stored on 17 March 2026, one folder per paper, and archives of 4 July 2026; four of its folders were never filled |
| `figures` | no | images of January and February 2026 and figure archives of 4 July 2026 |
| `paper` | no | made on 17 January 2026 in the project's first layout and never filled |

Every folder holds a `00-READ-ME.md` saying the same in two to four lines. The same map, with every experiment folder, is in the repository's [EXPERIMENTS-INDEX.md](https://github.com/MichaelDariusEastwood/arc-principle-validation/blob/main/EXPERIMENTS-INDEX.md).
