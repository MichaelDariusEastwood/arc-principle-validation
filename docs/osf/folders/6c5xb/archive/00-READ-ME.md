# archive

In use. The papers' PDFs, each file at the address OSF gave it when it was first stored. A file's name may be older than its contents: each file receives every new version of its paper, with every earlier version kept in the file's history. A file named "older copy" is an earlier address of the same paper and receives every new version too.

Each paper's own page and DOI: `00-START-HERE.md`, at the top of [this project's files](https://osf.io/6c5xb/files/osfstorage).
