# Priority and provenance

The dated record of when each part of this framework was first written down, and how a
reader can check that date without taking the author's word for it.

| File | What it is |
|------|------------|
| `PRIORITY-AND-PROVENANCE.md` | the record itself: what was stated, when, and what evidences the date |
| `PRIORITY-AND-PROVENANCE.html` | the same record as a page |
| `PRIORITY-AND-PROVENANCE.pdf` | the same record as a PDF |
| `PRIORITY-VERIFY.md` | how to verify each dated claim yourself |

The three copies of the record are the same content in three formats. Start with
`PRIORITY-VERIFY.md` if what you want is to check a date rather than read the account.

## What a date here does and does not establish

A date establishes when a statement existed. It does not establish that the statement is
correct, that it was first, or that no one else had reached it independently. Where earlier
or parallel work exists, it is named in the record and in the repository `README.md` rather
than left for a reader to find.
